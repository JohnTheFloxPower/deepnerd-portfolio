# NowBlangis — Portfólio de Tecnologia

Portfólio autoral de um estudante de **Engenharia de Software na Estácio**, localizado em Brasília (DF), com foco em oportunidades de **estágio em desenvolvimento** e **desenvolvimento júnior**.

O site mantém uma estética **dark / terminal / hacker**, mas organiza as informações para que recrutadores encontrem com facilidade a formação, as tecnologias estudadas, os projetos e os canais de contato.

## Tecnologias deste site

- HTML5 semântico
- CSS3 responsivo, grid e animação discreta
- JavaScript para atualização automática do ano
- Sem dependências, frameworks ou etapa de compilação

> **Importante:** React, Three.js, Java e Minecraft Forge são tecnologias mencionadas nos projetos apresentados, não dependências deste site estático.

## Projetos em destaque

| Projeto | Contexto | Tecnologias / área |
| --- | --- | --- |
| **Kamehameha Core** | Mod experimental para Minecraft 1.20.1 com efeitos de ataque energético, partículas e interação destrutiva com blocos | Minecraft Forge, efeitos visuais |
| **Jogo 3D experimental** | Protótipo com HUD de sanidade/esperança, lanterna, monstro, diálogos e inventário | React, Three.js, JavaScript |
| **GEEK WORLD** | Projeto acadêmico criado durante a graduação, com exercício de programação em Java | Java |

**Transparência:** este repositório contém o código do **site de portfólio**, e não o código-fonte completo desses três projetos. Links para demonstrações e repositórios específicos poderão ser adicionados à medida que forem organizados/publicados. Não são atribuídas funcionalidades não verificadas além das descrições informadas pelo autor.

## Executar localmente

Basta abrir `index.html` no navegador. Para servir com um servidor local opcional:

```bash
python -m http.server 8000
```

Em seguida, abra `http://localhost:8000`.

## Publicação com GitHub Pages

Após aprovar e integrar as alterações à branch principal, acesse **Settings → Pages** no repositório e configure a publicação a partir de **main** e da pasta **/(root)** (caso ainda não esteja configurada). O GitHub informará o endereço público do site.
